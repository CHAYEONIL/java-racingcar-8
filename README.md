#  자동차 경주 게임

##  기능 요구사항

### 입력
- 경주할 자동차 이름 (쉼표로 구분, 5자 이하)
- 시도할 횟수 (양수)

### 동작
- 0~9 사이의 무작위 값 생성
- 무작위 값이 **4 이상**이면 전진, **4 미만**이면 정지
- 매 라운드마다 모든 자동차의 상태 출력

### 출력
- 각 라운드별 자동차 이름과 위치 (`-`로 표시)
- 최종 우승자 (공동 우승 가능, 쉼표로 구분)

### 예외 처리
- 잘못된 입력 시 `IllegalArgumentException` 발생 후 종료

##  구현 기능 목록

### 1단계: 도메인 로직 구현

#### `Car` - 자동차
-  이름과 위치를 가지는 자동차 객체 생성
-  초기 위치는 0으로 설정
-  무작위 값(0~9)을 생성하여 이동 여부 결정
-  무작위 값이 4 이상이면 위치를 1 증가
-  현재 위치를 반환하는 기능
-  자동차 이름을 반환하는 기능

#### `Cars` - 자동차 컬렉션
-  여러 대의 자동차를 리스트로 관리
-  모든 자동차를 한 번씩 이동 시도
-  가장 많이 이동한 위치 계산
-  최대 위치에 있는 모든 자동차를 우승자로 반환

#### `RacingGame` - 게임 진행
-  지정한 횟수만큼 라운드 반복
-  각 라운드마다 모든 자동차 이동
-  라운드별 자동차 상태 저장

<br>

### 2단계: 입력 검증 로직

#### `InputValidator` - 유효성 검증
-  자동차 이름 길이 검증 (5자 이하)
-  자동차 이름 공백 검증
-  자동차 이름 중복 검증
-  시도 횟수 양수 검증
-  시도 횟수 숫자 형식 검증
-  검증 실패 시 `IllegalArgumentException` 발생

<br>

### 3단계: 입출력 처리

#### `InputView` - 사용자 입력
-  자동차 이름 입력 안내 메시지 출력
-  자동차 이름 문자열 입력받기
-  쉼표(`,`)로 이름 분리하여 리스트 반환
-  시도 횟수 입력 안내 메시지 출력
-  시도 횟수 입력받아 정수로 변환

#### `OutputView` - 결과 출력
-  "실행 결과" 헤더 출력
-  자동차별 이름과 위치 출력 (`이름 : ---`)
-  위치만큼 `-` 문자 반복
-  라운드 사이 빈 줄 출력
-  최종 우승자 출력 (단독/공동)

<br>

### 4단계: 통합

#### `Application` - 메인 로직
-  입력 → 검증 → 실행 → 출력 흐름 연결
-  예외 발생 시 프로그램 종료

##  테스트

### 테스트 실행
```bash
./gradlew test
```

### 테스트 케이스

#### Car 테스트
- 자동차 생성 및 초기 상태 확인
- 무작위 값에 따른 이동 동작 검증
- 전진 시 위치 증가 확인

#### Cars 테스트
- 여러 자동차 생성 및 관리
- 단독/공동 우승자 판정 로직

#### InputValidator 테스트
- 이름 길이 초과 예외
- 빈 이름 예외
- 중복 이름 예외
- 시도 횟수 음수/0 예외
- 시도 횟수 숫자 형식 예외

#### RacingGame 테스트
- 라운드 횟수만큼 게임 진행 확인
